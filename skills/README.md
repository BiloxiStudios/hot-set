# HOT SET starter skills

Six small, generic skills from building HOT SET, a UEFN game made with a crew of AI agents in four days for the 2026 Epic AI MegaJam. Each one is a short synopsis of a rule that cost us time, written so you can drop it into your own agent setup (an AGENTS.md, a skills folder, or a system prompt).

| skill | one line |
|---|---|
| [upload-moderation-gate](upload-moderation-gate.md) | never let an agent upload an asset again before the validation failure is fixed |
| [persona-actions-char-budget](persona-actions-char-budget.md) | count your NPC's registered-action text before you push; past 2000 characters the NPC goes silent |
| [agent-leash-basics](agent-leash-basics.md) | lanes, labels and gates that keep fast agents from repeating a mistake fast |
| [frame-safe-public-crops](frame-safe-public-crops.md) | crop and check screenshots and clips before they go public |
| [honest-devlog](honest-devlog.md) | PLAYED / BUILT / NOT seen: a devlog that never claims more than someone saw |
| [ui-widget-blueprints-first](ui-widget-blueprints-first.md) | every player-facing screen is a Widget Blueprint; Verse holds data and events only |

These are starters, not the full toolkits: short, plain markdown, no project paths or secrets. Adapt the names and numbers to your project.

The story behind them is in the HOT SET postmortem: https://www.biloxistudios.com/blog/megajam26-postmortem
